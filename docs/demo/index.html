What is real here?

Local file hashing, filename/extension recognition, JSON parsing, CycloneDX/SPDX component normalization, and policy checks execute in-browser. No upload occurs.

What is simulated?

Recursive ZIP/TAR/container traversal uses deterministic production-shaped sample results because browsers do not expose Swift's Python archive engine. The actual CLI performs that work locally.
